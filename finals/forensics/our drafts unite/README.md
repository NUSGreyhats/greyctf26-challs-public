# Name

Our Drafts Unite

# Description

There was a recent fire in Lumière that tragically took the life of an up and coming NUS Greyhats pubs artist, Verso. Rumours were abound that he was working on his final magnum opus, a flag! However, Verso famously bragged that the flag would come about only when both of the drafts he was working on, "united", whatever that means.

The police have managed to obtain the following leads:

1. The damaged remains of the 1st draft
2. The file image of the workshop's laptop, which only Verso and Monoco, Verso's assistant and the suspected arsonist, had access to

Can you find the 2 drafts and bring to light the flag?
