# Name

Long Khipu Braids

# Description

Alice and Bob are learning about the ancient Incan civilization, and decided to
fool Mallory this time by using a khipu-inspired scheme to perform their key exchange.

Picture convention:

- Bob publishes the `bob_P_*` cords.
- Alice publishes the `alice_E_*` cords.
- Strands are numbered where they attach to the primary cord.
- Read crossings from the primary cord downward.
- Each horizontal register contains exactly one adjacent crossing.
- A positive crossing has the left/top strand pass over the adjacent right
  strand; a negative crossing has it pass under.
- At each crossing, the strand drawn on top is the over-strand; the other strand
  continues underneath it.
- The side knots are just khipu-style register markers; ignore them when
  reading the crossings.
